# MYM (MoveYourMusic)

Website, privacy policy and support for the MYM iPhone app — a free,
non-commercial personal project that mirrors your Spotify and YouTube Music
mixes into Apple Music. No ads, no purchases, no data collection.

- Site: https://ln-bodicherla.github.io/mym-app/
- Privacy: https://ln-bodicherla.github.io/mym-app/privacy/
- Support: https://ln-bodicherla.github.io/mym-app/support/

Questions or bugs: [open an issue](https://github.com/ln-bodicherla/mym-app/issues/new).
